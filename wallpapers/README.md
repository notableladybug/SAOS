# SAOS Wallpapers

Wallpapers go in this directory. They will be copied to `/usr/share/backgrounds/saos` on the installed system.

## Requirements

- **Format:** PNG or JPG
- **Aspect ratio:** 16:9 recommended
- **Colors:** Black background (#000000) with green accents (#00ff41)
- **Theme:** Topographic/technical/spy aesthetic
- **Dimensions:** 3840x2160px or higher

## File naming

Use `saos-<name>.png` format:
- `saos-default.png` — default wallpaper at boot
- `saos-matrix.png` — matrix-style code rain
- `saos-topographic.png` — topographic map style

Ensure one file is named `saos-default.png` to be used as the system default.
